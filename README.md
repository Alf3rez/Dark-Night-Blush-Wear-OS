# Dark Night Blush Watch Face for Wear OS
<p align="center">
<img src="pictures/One%20Plus%20Watch%202%20sample.png" alt="OnePlus Watch 2 Sample" width="400">
</p><br><br>

This watch face is heavily inspired in my beloved Dark Night Blush from Amazfit GTS.<br>
I tried to maintain the original appearance without sacrificing freedom, so the battery, steps and hearth rate compilations are customizable, but by default are the same as the original Amazfit one.<br><br><br>

<br><br>Made with [WatchFaceStudio](https://developer.samsung.com/watch-face-studio/overview.html). The minimum target API is 34 (the program doesn't let export to a lower level), so should work in any device with at least Wear OS 5.0, and obviously, much better in rounded ones. The text is intentionally small to keep the design elegant and minimal. It should work well on a 46 mm watch, but it may be too small on a 42 mm watch. Let me know if that’s the case and you’d like a larger version, and I’ll export one with larger elements.
